# 🔧 NATRIUM

Официальный сайт оптимизированной сборки NATRIUM. Проект создан для повышения производительности Minecraft и предоставления удобного инструмента для кастомизации игрового процесса.

---

## 🛠️ Особенности сборки

* **Высокая оптимизация:** Значительный прирост FPS и стабильная генерация чанков.
* **Удобный экспорт:** На сайте можно отфильтровать моды по категориям и выгрузить текстовый список (.txt) для кастомизации или сверки.
* **Широкая поддержка:** Готовые конфигурации для множества версий игры, включая актуальные релизы (1.16.5, 1.18.2, 1.20.1, 1.21.x, 26.1).

---

## ⚙️ Установка

### Вариант 1: Использование файлов `.mrpack` (Рекомендуемый)
1. Скачайте необходимый `.mrpack` файл из данного репозитория или через официальный сайт.
2. Импортируйте файл в любой современный лаунчер с поддержкой формата Modrinth (например, Prism Launcher, Modrinth App, ATLauncher или TL Legacy).

### Вариант 2: Ручная установка (`.zip` архив)
> ⚠️ **Важно:** На официальном сайте напрямую скачать архив `.zip` нельзя. Его можно найти в официальном Telegram-канале проекта или на странице Minecraft Inside.

1. Скачайте архив со сборкой.
2. Распакуйте содержимое в вашу папку с модами. 
3. *Обратите внимание:* путь к корневой папке игры может отличаться от стандартного `.minecraft` в зависимости от используемого лаунчера или операционной системы (например, при использовании сторонних лаунчеров папка сборки может находиться в `.../instances/` или `.../profiles/`). Проверьте настройки своего лаунчера перед переносом файлов.

# 🔧 NATRIUM

The official website of the optimized NATRIUM modpack. This project is designed to improve Minecraft performance and provide a user-friendly tool for gameplay customization.

---

## 🛠️ Features

* **High Optimization:** Significant FPS boost and stable chunk generation.
* **Convenient Export:** Filter mods by category on the website and export a text list (.txt) for personal customization or verification.
* **Wide Support:** Ready-to-use configurations for multiple game versions, including current releases (1.16.5, 1.18.2, 1.20.1, 1.21.x, 26.1).

---

## ⚙️ Installation

### Method 1: Using `.mrpack` files (Recommended)
1. Download the required `.mrpack` file for your game version from this repository or the official website.
2. Import the file into any modern launcher that supports the Modrinth format (such as Prism Launcher, Modrinth App, ATLauncher, or TL Legacy).

### Method 2: Manual Installation (`.zip` archive)
> ⚠️ **Important:** You cannot download the `.zip` archive directly from the official website. It can be found in the project's official Telegram channel or on the Minecraft Inside page.

1. Download the modpack archive.
2. Extract the contents into your mods folder.
3. *Please note:* The path to the game's root folder may differ from the standard `.minecraft` directory depending on your launcher or operating system (for example, when using third-party launchers, the instance folder might be located in `.../instances/` or `.../profiles/`). Check your launcher settings before moving the files.
